# 🧠 Fake Personality Scanner

**CLASSIFIED PERSONALITY ANALYZER**

An interactive, satirical personality scanner that uses randomised scoring, keyword detection, and completely unnecessary threat assessments to analyse someone's supposed behavioural tendencies.

Is the subject a harmless human, a sleep-deprived goblin, or an aspiring supervillain? The scanner has absolutely no scientific authority, but it does have charts.

## ✨ Features

### 🧪 Multiple Interface Themes
Choose between three different visual environments:

- **Evil Laboratory:** Purple-themed experimental interface.
- **Corporate Scam AI:** Blue-themed corporate analysis system.
- **Government Classified:** Green-themed classified intelligence interface.

### 🔍 Chaos Scan
Enter behavioural data and run a simulated personality analysis.

The scanner generates several fictional indicators:

- Goblin Energy
- Villain Probability
- Sleep Deprivation Index
- Meme Consumption
- Keyboard Rage
- Social Battery

### 📊 Visual Analysis
The results include three interactive charts:

- **Radar Chart:** Displays different behavioural indicators.
- **Pie Chart:** Shows the fictional distribution of personality metrics.
- **Line Chart:** Displays a simulated sleep-quality trend.

### 🎭 Randomised Results
The analysis combines keyword-based scoring with randomised values to generate unpredictable results.

### 🖼️ Downloadable Result Card
Generate and download a PNG image containing the scan results.

### 💻 Matrix Background
A continuously animated digital-rain effect adds to the classified-system aesthetic.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- html2canvas
- HTML Canvas API

External libraries are loaded through CDN links.

## 🚀 Running the Project

### Run Locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Enter some fictional behavioural data.
4. Select a theme.
5. Click **RUN CHAOS SCAN**.

### Run Online

The project can be hosted using **GitHub Pages**.

Once deployed, it can be accessed through its GitHub Pages URL.
